# ⛽ Gasolina ou Álcool

Aplicativo Android desenvolvido em Java que calcula qual combustível é mais vantajoso entre gasolina e álcool com base no preço informado pelo usuário.

O projeto foi criado com foco em estudos de desenvolvimento mobile Android, manipulação de interface gráfica e lógica condicional.

---

# 🚀 Tecnologias utilizadas

* Java
* Android Studio
* Android SDK
* XML para construção de layouts
* Git e GitHub

---

# 📱 Funcionalidades

* Inserção do valor da gasolina
* Inserção do valor do álcool
* Cálculo automático da melhor opção
* Exibição do resultado na tela
* Validação básica de campos
* Interface gráfica mobile

---

# 🖥️ Interface da aplicação

O aplicativo possui interface gráfica Android desenvolvida com XML.

Através dela o usuário pode:

* informar os preços dos combustíveis;
* calcular automaticamente a melhor escolha;
* visualizar o resultado diretamente na tela.

# ▶️ Como executar o projeto

## Pré-requisitos

* Android Studio
* Android SDK instalado
* Emulador Android ou dispositivo físico

---

## Clone o repositório

```bash
git clone https://github.com/lucascrippa7/Android-Gasolina-ou-lcool.git
```

---

## Abra o projeto

No Android Studio:

* Selecione `Open Project`
* Abra a pasta do projeto

---

## Execute a aplicação

* Inicie um emulador Android
* Ou conecte um dispositivo físico
* Execute utilizando o botão `Run`

---

# 📚 Regra utilizada

O cálculo segue a regra tradicional:

* Se o valor do álcool for até 70% do valor da gasolina, o álcool é mais vantajoso.
* Caso contrário, a gasolina é a melhor opção.
